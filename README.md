# 🌐 Personal Portfolio Website

This repository contains the source code for my **personal portfolio website**, built with **React** and hosted on **AWS S3 + CloudFront**.  
The site showcases my projects, skills, and experience as a data scientist and cloud consultant.

---

## 🚀 Live Demo

👉 [View the website](https://benpollins.com)

---

## 🧰 Tech Stack

- **React** – Frontend framework  
- **Tailwind CSS** – Styling and layout  
- **Lucide Icons** – Icon set  
- **AWS S3** – Static site hosting  
- **AWS CloudFront** – Global CDN distribution  
- **Yarn / npm** – Package management
